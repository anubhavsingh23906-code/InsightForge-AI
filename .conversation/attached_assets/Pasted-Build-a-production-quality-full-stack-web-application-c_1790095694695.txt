Build a production-quality full-stack web application called:

INSIGHTFORGE AI

Tagline:
"Turn questions into trusted intelligence."

PROJECT PURPOSE
----------------
InsightForge AI is an AI-powered data intelligence platform.

A user should be able to ask a data-related question in plain English, and the application should:

1. Understand the user's question.
2. Convert it into a structured analysis plan.
3. Identify the required data.
4. Select appropriate available data sources.
5. Collect or load data.
6. Validate and clean the data.
7. Analyze the data.
8. Automatically choose useful visualizations.
9. Generate explainable AI insights.
10. Show evidence and data provenance.
11. Present the results in an interactive dashboard.
12. Allow the user to export the analysis.

IMPORTANT:
This is NOT supposed to be a generic chatbot.
The core product is an AI DATA ANALYST / DATA INTELLIGENCE PLATFORM.

The interface should make the AI workflow visible to the user.
